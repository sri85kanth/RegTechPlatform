# Gujarati (gu) terminology — for native-speaker review

Register: formal (આપ / આપનું / આપની, imperatives in -ઓ: કરો, જુઓ). "Us/our" for the company = આપણે/આપણા (inclusive). Sentences end with ".". Digits stay Latin (0–9).
Kept unchanged: Company Brain, NABH, SEBI, DPDP, SOP, CSV, PDF, API, AI, OCR, ID, CIN, JSON, file-format names (Excel, Word, Markdown), ₹, Cr, ≥, %, …, "Ramprasad".
