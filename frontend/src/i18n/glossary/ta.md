# Tamil (ta) glossary — Company Brain

These are the core terms fixed before translating `locales/ta.json`. Each concept uses one term in every string. A native-speaker reviewer should check these first; changing a term here means changing it everywhere in `ta.json`.

Register: formal, using நீங்கள் / உங்கள். "Us" / "our" (the company) is the inclusive நாம் / நமக்கு / நமது. Buttons use the polite imperative (-வும்), for example நீக்கவும் and சரிபார்க்கவும். Navigation items and labels use nouns.

| English | Tamil | Note |
|---|---|---|
| Compliance | இணக்கம் | Combining form இணக்க- (இணக்க மேலாளர் = Compliance manager). |
| Regulation | ஒழுங்குமுறை (pl. ஒழுங்குமுறைகள்) | Also used for "Regulatory" (ஒழுங்குமுறை மாற்றங்கள்). "Rule" in general = விதி. |
| Regulator | ஒழுங்குமுறை அமைப்பு | "Regulatory body". Used for RBI, SEBI, NABH and so on. |
| Requirement | தேவைப்பாடு | Chosen over the generic தேவை ("need"), so that a legal requirement is not confused with an everyday need. |
| Obligation | கடமை | |
| Duty | கடமை | In this app "duty" is a synonym for obligation, so both use one word. |
| Control | கட்டுப்பாடு | An internal control measure. It never stands for "regulation" (ஒழுங்குமுறை), so the two do not collide. "Controlled document" = கட்டுப்படுத்தப்பட்ட ஆவணம். |
| Evidence | சான்று | "Certificate" = சான்றிதழ் (a different word). |
| Applicability | பொருந்துதன்மை | |
| Applies / Applicable | பொருந்தும் | "Does not apply" / "Not applicable" = பொருந்தாது. "Conditionally applicable" = நிபந்தனையுடன் பொருந்தும். |
| Applies to us | நமக்குப் பொருந்தும் | The nav item "What applies to us" = நமக்கு எவை பொருந்தும். |
| Gap | இடைவெளி | A shortfall against a requirement. "Close gaps" = இடைவெளிகளை நிரப்பவும். |
| Partial | பகுதியளவு | |
| Met / Not met | நிறைவேறியது / நிறைவேறவில்லை | The requirement is fulfilled or not. |
| Covered / Not covered | உள்ளடக்கப்பட்டது / உள்ளடக்கப்படவில்லை | "Not covered" means no document addresses the requirement. A control "covering" a requirement = உள்ளடக்குகிறது. |
| Documented | ஆவணப்படுத்தப்பட்டது | A document covers the requirement. This is not "implemented" (செயல்படுத்தப்பட்டது). |
| Finding | கண்டறிவு (pl. கண்டறிவுகள்) | Kept separate from கண்டுபிடிப்பு, the "Discover" pipeline step, and from கண்டறியப்பட்ட ("detected"). |
| Owner | பொறுப்பாளர் | The accountable person. உரிமையாளர் (property owner) was avoided. "Responsible" = பொறுப்பானவர். "Ownership" = பொறுப்பு. |
| Department | துறை | Industry "sector" = தொழில் துறை, to keep it apart from a hospital department. |
| Policy | கொள்கை | |
| SOP | SOP | Kept in Latin script. Plural SOP-கள். |
| Auditor | தணிக்கையாளர் | "Audit trail" = தணிக்கைத் தடம். |
| Dashboard | டாஷ்போர்டு | A transliteration, since this is the word users actually say. |
| Impact | தாக்கம் | "Impact cascade" / "Cascade" = தாக்கச் சங்கிலி. "Impact engine" = தாக்கப் பொறி. |
| Risk | இடர் | "Risk register" = இடர்ப் பதிவேடு. "Risk bands" = இடர் நிலைகள். |
| Critical / High / Medium / Low | தீவிரம் / அதிகம் / நடுத்தரம் / குறைவு | Risk and severity bands. "Criticality" = தீவிர நிலை. "Critical Functions" (business-essential functions) = முக்கியச் செயல்பாடுகள். |
| Verify / Verified / Verification | சரிபார்க்கவும் / சரிபார்க்கப்பட்டது / சரிபார்ப்பு | A human verification of a record. |
| Confirm | உறுதிப்படுத்து | "Not confirmed yet" = இன்னும் உறுதிப்படுத்தப்படவில்லை. |
| Approve / Approved | ஒப்புதல் அளிக்கவும் / ஒப்புதல் பெற்றது | "Approver" = ஒப்புதல் அளிப்பவர். |
| Review / Reviewer | மறுஆய்வு / மறுஆய்வாளர் | "Needs review" = மறுஆய்வு தேவை. |
| Assess / Assessment | மதிப்பிடு / மதிப்பீடு | "Estimated" is தோராயமாகக் கணிக்கப்பட்ட, to keep it apart from "assessed". |
| Check (against documents) | ஆய்வு | "Requirements checked" = ஆய்வு செய்யப்பட்ட தேவைப்பாடுகள். This keeps it apart from verify (சரிபார்) and test (சோதனை). |
| Test (a control) | சோதனை | |
| Document / Record / Register | ஆவணம் / பதிவு / பதிவேடு | பதிவு also means "registration". The context tells them apart. |
| Licence | உரிமம் | |
| Mapped / Linked | இணைக்கப்பட்டது | "Mapped to a control" and "linked" are the same action in this app. பொருத்து was avoided because it looks like பொருந்தும் (applies). |
| Matches / Does not match | ஒத்துப்போகிறது / ஒத்துப்போகவில்லை | Also kept apart from பொருந்தும் (applies). |
| Open (unresolved finding, gap or risk) | தீர்க்கப்படாத | |
| File (place a record in the structure) | சேர் | "Filed" = சேர்க்கப்பட்டது. "Not filed yet" = இன்னும் சேர்க்கப்படவில்லை. |
| Delegation | பொறுப்பு ஒப்படைப்பு | |
| Clause / Section / Chapter | உட்பிரிவு / பிரிவு / அத்தியாயம் | |
| Amendment | திருத்தம் | |
| NABH Core element | NABH மையக் கூறு | "Element" = கூறு. "Asterisk (*)" = நட்சத்திரக் குறி. |
| Entity (graph record) | உருப்படி | "Legal entity" = சட்ட நிறுவனம். |
| Graph (company graph) | இணைப்பு வரைபடம் | |
| Source | மூலம் | |
| Upload / Download | பதிவேற்று / பதிவிறக்கு | |
| Sign in / Sign out | உள்நுழை / வெளியேறு | |
