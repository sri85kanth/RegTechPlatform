# Marathi (mr) glossary — Company Brain UI

Conventions: formal तुम्ही / तुमचे (आपल्याला = “us”, inclusive); imperative buttons end in “-ा” (जोडा, पडताळा). Full sentences end with “.” (modern Marathi usage, never “।”); labels and fragments have no end mark. Product name, acronyms (NABH, SOP, CSV, API, AI, ID …), ₹/Cr/≥/…/· and `{placeholders}` are kept unchanged.
