# Malayalam (ml) glossary — Company Brain

These are the core terms fixed before translating `locales/ml.json`. Each concept uses one term in every string. A native-speaker reviewer should check these first; changing a term here means changing it everywhere in `ml.json`.

Register: formal നിങ്ങൾ / നിങ്ങളുടെ, the standard polite form in Malayalam software UI. താങ്കൾ would be more deferential, but it reads stiff in menus. "Us" / "our" (the company) is നമുക്ക് / നമ്മുടെ. Buttons use the -ുക form, for example ഇല്ലാതാക്കുക and സ്ഥിരീകരിക്കുക.

| Regulation | ചട്ടം (pl. ചട്ടങ്ങൾ) | Also "Regulatory" (ചട്ടമാറ്റങ്ങൾ = Regulatory changes) and "rules". നിയന്ത്രണം is kept for Control only. |
| Regulator | റെഗുലേറ്റർ | A transliteration, as used in Malayalam news for RBI and SEBI. നിയന്ത്രണ ഏജൻസി would collide with Control. |

Placeholders: a `{name}` never takes a case suffix. Use എന്ന (`{company} എന്ന കമ്പനിയുടെ`), a colon label (`റിസ്ക്: {level}`), or a noun after it that carries the suffix (`ആകെ {total} എണ്ണത്തിൽ {n}`).
