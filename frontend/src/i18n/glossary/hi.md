# Hindi (hi) glossary — Company Brain UI

Conventions: formal आप; imperative buttons end in “-ें” (जोड़ें, सत्यापित करें). Full sentences end with “।”; labels and fragments have no end mark. Nukta is used (दस्तावेज़, फ़ाइल). Product name, acronyms (NABH, SOP, CSV, API, AI, ID …), ₹/Cr/≥/…/· and `{placeholders}` are kept unchanged.
