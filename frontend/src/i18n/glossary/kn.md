# Kannada (kn) glossary: Company Brain UI

Core terms fixed before translation and used across all strings in `locales/kn.json`.
Register: formal (ನೀವು). "Us/our" = ನಾವು / ನಮಗೆ / ನಮ್ಮ.
Kept in Latin script: Company Brain, NABH, SEBI, DPDP, SOP, CSV, PDF, API, AI, OCR, ID, URL, CIN, Excel/Word/Markdown, ₹, Cr, %.

| English | Kannada | Note |
|---|---|---|
| Compliance | ಅನುಸರಣೆ | Standard term. |
| Regulation (instrument) | ನಿಯಮಾವಳಿ (pl. ನಿಯಮಾವಳಿಗಳು) | A body of regulations, as in ಕಟ್ಟಡ ನಿಯಮಾವಳಿ. It names the document or instrument, so ನಿಯಮ stays free for "rule". "Regulatory" (attributive) also uses ನಿಯಮಾವಳಿ, e.g. ನಿಯಮಾವಳಿ ಬದಲಾವಣೆಗಳು. |
| Regulator | ನಿಯಂತ್ರಕ ಸಂಸ್ಥೆ | Always written with ಸಂಸ್ಥೆ, so it is never confused with Control. |
| Rule | ನಿಯಮ | |
| Control (internal control) | ನಿಯಂತ್ರಣ (pl. ನಿಯಂತ್ರಣಗಳು) | Never used for regulation. |
| Requirement | ಅವಶ್ಯಕತೆ | |
| Obligation | ಬಾಧ್ಯತೆ | Legal obligation. |
| Duty | ಕರ್ತವ್ಯ | The app uses "duty" alongside "obligation", so it gets a separate word. |
| Evidence | ಸಾಕ್ಷ್ಯ | Legal evidence (cf. Bharatiya Sakshya Adhiniyam). The verb "proves" is ಸಾಬೀತುಪಡಿಸು. |
| Applicability | ಅನ್ವಯಿಸುವಿಕೆ | "Applies" = ಅನ್ವಯಿಸುತ್ತದೆ, "Not applicable / Does not apply" = ಅನ್ವಯಿಸುವುದಿಲ್ಲ. |
| Applies to us | ನಮಗೆ ಅನ್ವಯಿಸುತ್ತದೆ | "Apply to us" (count label) = ನಮಗೆ ಅನ್ವಯಿಸುವವು. |

| Covered / Not covered | ಒಳಗೊಂಡಿದೆ / ಒಳಗೊಂಡಿಲ್ಲ | "Not covered" means no document addresses it. Coverage = ಒಳಗೊಳ್ಳುವಿಕೆ (not ವ್ಯಾಪ್ತಿ, which is Scope). |
| Finding (audit) | ಪರಿಶೋಧನಾ ಅಂಶ (pl. ಪರಿಶೋಧನಾ ಅಂಶಗಳು) | "Audit point". ಅವಲೋಕನ was avoided because it also reads as "overview". |

| Filed (sorted into a department) | ಕಡತಕ್ಕೆ ಸೇರಿದೆ | ಕಡತ is the government term for a file. "Not filed yet" = ಇನ್ನೂ ಕಡತಕ್ಕೆ ಸೇರಿಲ್ಲ. |

## For the reviewer

- **"Effective"** is one key with two meanings: it is a date column ("Effective" date of a regulation or document), and it is also the control-effectiveness status (Effective / Partially effective / Ineffective). It is rendered as ಜಾರಿಯಲ್ಲಿ ("in effect"), a compromise that fits both. Splitting it in code would let the effectiveness status read ಪರಿಣಾಮಕಾರಿ.
- **Regulation = ನಿಯಮಾವಳಿ.** If reviewers prefer the legislative term ವಿನಿಯಮ (as used for "Regulations" in statute translations), it is a single find-and-replace.
- **"Area"** (topic or chapter filter) = ವಿಷಯ, **"Domain"** = ಕ್ಷೇತ್ರ, **"Sector"** = ವಲಯ.
