# Bengali (bn) terminology — for native-speaker review

Register: formal (আপনি / আপনার, imperatives in -উন: করুন, দেখুন). Sentences end with "।". Digits stay Latin (0–9).
Kept unchanged: Company Brain, NABH, SEBI, DPDP, SOP, CSV, PDF, API, AI, OCR, ID, CIN, JSON, file-format names (Excel, Word, Markdown), ₹, Cr, ≥, %, …, "Ramprasad".
